# Friday V1 Implementation Plan

> Umsetzung mit subagent-driven-development für getrennte Provider und Reviews;
> die vorliegende Nutzeranweisung autorisiert die erste testbare Version.

**Ziel:** Hey-Friday-Overlay mit echter lokaler Laya-Inferenz und Computeraktionen.

**Architektur:** Zentrale native Audioaufnahme, zwei lokale Python-Worker, Hex-
Loopback-Service, typisierte Tools und ein gemeinsames UI-ViewModel.

**Stack:** SwiftUI/AppKit/AVFoundation, Python 3.12, Laya Core ML, Moonshine,
Hex/Whisper, Ollama, bestehende System-TTS und Thinking Orbs.

Entwurf: [Friday V1](../specs/2026-10-04-friday-v1-design.md).

- [ ] `services/local-runtime/pyproject.toml`, `uv.lock`, `friday_runtime/laya.py`,
  `__main__.py`, `tests/test_laya.py`: JSON-Laya-Worker, Schema, Offline-Modell,
  Trunkierung ablehnen; Fixturetests und tatsächliche deutsche Inferenz.
- [ ] `friday_runtime/wake.py`, `tests/test_wake.py`: Moonshine-Blöcke von stdin,
  normalisierte vollständige Hey-Friday-Phrase, Ready/Wake-Events, Reset/Stop.
- [ ] `scripts/setup-local-runtime.sh`, `scripts/prepare-local-models.py`:
  Python-3.12-Umgebung, gepinnte Modelle, offizielles Hex-Binary, Runtime-JSON.
- [ ] `FridayAdapters/Runtime/RuntimeConfiguration.swift`, `JSONLineProcess.swift`,
  `Laya/LayaDecisionEngine.swift`, `ActionArgumentParser.swift`: Workerstart,
  Bereitschaft, Request-ID, Deadline, stderr-Logs, Abbruch und typisierte Argumente.
- [ ] `FridayAdapters/Hex/HexService.swift`, `HexSpeechToText.swift`: API-2-Handshake,
  Modellvorbereitung, WAV-HTTP, finale Transkripte und Helper-Lebenszyklus.
- [ ] `FridayAdapters/Audio/AudioInput.swift`, `WAVEncoder.swift`,
  `WakeWord/MoonshineWakeWordDetector.swift`: zentrale 16-kHz-Audioquelle,
  Ringpuffer, Pegel/Silenz-Endpunkt, ein Mikrofonzugriff, Wake-IPC.
- [ ] `FridayAdapters/Tools/MacToolExecutor.swift`, `Reasoning/OllamaReasoningEngine.swift`:
  App-Start, Markdown-Notizen, lokales LLM mit Deadline/Stop und finale Antwort.
- [ ] `FridayApp/AssistantViewModel.swift`, `AssistantView.swift`, `MascotPanel.swift`,
  `FridayApp.swift`, `AssistantOrb.swift`, `FridayCore/Contracts.swift`: echte Verdrahtung,
  Phasen, Wake-Opt-in, Aufnahme/Stop, Statusanzeige, Abbruch/Beenden und Overlay.
- [ ] `scripts/build-macos.sh`, README, Architektur/Roadmap und Tests anpassen.
  `uv run --project services/local-runtime pytest`, `swift test --package-path apps/macos`,
  synthetische Audio-/Laya-/Hex-Smokes, App-Build und Signatur prüfen.
- [ ] Nach Review in main übernehmen, pushen und die lokale App für den Test bereitstellen.
