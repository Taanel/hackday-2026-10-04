# Friday

Friday is a German-language macOS menu-bar voice assistant for its owner. It uses local wake detection, dictation and Laya routing; Gemini answers complex questions. Users want quick, quiet computer actions, trustworthy Home Assistant control and spoken answers.

The everyday screen needs recording, typed input, status, answers and selectable search results. Advanced setup belongs in separate settings categories. Local window, tab and file searches keep contents on the Mac. The overlay is transparent and unobtrusive, with a static idle orb and short-lived transcripts. Weather can appear as a compact sourced forecast beneath the orb.

Existing behavior and locally stored credentials must survive UI changes. Do not automatically restart the running app or run unrelated test suites.
